## Què és Python?

Python és un llenguatge de programatge d'alt nivell, interpretat i de codi obert. És conegut per la seva llegibilitat i simplicitat sintàctica, cosa que el fa ideal per a principiants i professionals per igual.

!!! info "Per què Python?"
    - Sintaxi clara (sembla pseudocodi).
    - Gran comunitat i suport.
    - Utilitzat en ciència de dades, web, automatització i IA.

## Instal·lació

Necessites instal·lar Python al teu ordinador. 

1. Ves a [python.org](https://www.python.org/downloads/).
2. Descarrega la versió més recent (Python 3.x).
3. Executa l'instal·lador. 
    - **Windows:** Marca la casella *"Add Python to PATH"* abans d'instal·lar.
    - **Mac/Linux:** Segueix les instruccions gràfiques o usa el gestor de paquets.

## El teu primer editor

Tot i que pots usar qualsevol editor de text pla, recomanem:

- **Thonny**: Ideal per a principiants absoluts (veuràs les variables pas a pas).
- **VS Code**: Més potent, estàndard industrial.

!!! warning "Evita Word o Pages!"
    Mai escriguis codi en processadors de text com Microsoft Word. Han de ser editors de **text pla** (.txt, .py).
