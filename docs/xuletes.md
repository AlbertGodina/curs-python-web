# Xuletes imprimibles 🖨️

Resums d'una pàgina, en format **PDF (A4)**, perquè els tinguis a mà mentre programes. Imprimeix-los o desa'ls al teu dispositiu.

## Xuleta global

Tot el curs en una sola pàgina: entrada i sortida, variables i tipus, operadors, text, decisions, bucles, funcions, llistes, errors habituals i format del lliurament.

[📄 Descarrega la xuleta global](recursos/xuleta-global.pdf){ .md-button .md-button--primary }

## Xuletes per unitat

Un full per a cada unitat (de la 0 a la 7), amb la sintaxi nova, els errors típics i un recordatori del lliurament. Estan en un sol PDF de 8 pàgines: imprimeix només la que necessitis.

[📄 Descarrega les xuletes per unitat](recursos/xuletes-unitats.pdf){ .md-button }

!!! tip "Consell"
    Escriu el teu nom a la capçalera de cada full abans d'imprimir-lo, i **no et limitis a llegir-lo**: tenir-lo a mà mentre programes és el que t'ajudarà de veritat.
